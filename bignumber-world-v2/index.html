04 · BUILT TO EXTEND

이 페이지는 데이터로 자랍니다

새 테마 팩, 새 게임 규칙, 새 제휴 브랜드, 외부 DB까지. 코드를 뜯지 않고 붙일 수 있게 콘텐츠·규칙·저장소를 각각 분리해 두었습니다.

A

새 테마 팩 = JSON 한 개

data/packs.json에 항목을 추가하고 data/packs/<id>.json을 놓으면 덕후 월드·크로스오버·연승전·줄세우기에 자동으로 편입됩니다.

B

새 게임 규칙 = 모드 1개

assets/modes.js에 init · renderQuestion · evaluate · getShareSummary를 가진 객체를 등록하면 끝. 범위 추정 배틀, O/X 스피드전도 같은 방식입니다.

C

브랜드 전용 URL = ?brand=

data/brands.json에 브랜드를 추가하면 ?brand=아이디 주소가 바로 생깁니다. 전용 색·슬로건·문제·CTA가 한 번에 바뀝니다.

🛡️ ?brand=dblife 미리보기 🍜 ?brand=shinramyun

ADAPTER SEAM

지금은 정적 JSON + localStorage, 내일은 시트·DB

PackRepository · ScoreStore · LeadRepository 세 어댑터만 교체하면 Google Sheets, Supabase, 자체 API로 그대로 옮겨집니다.

// assets/adapters.js
PackRepository   → Static · Sheets · REST
ScoreStore       → Local  · Supabase
LeadRepository   → Local  · Webhook
// data/config.json
{ "repository": "static" }

※ 위 링크는 실제로 동작하는 화이트라벨 데모입니다. 브랜드 팩은 가상 제휴 예시이며 실제 결제·쿠폰은 없습니다.
